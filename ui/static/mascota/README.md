# Mascota FA CUP (kiosko)

Pon aquí las imágenes de la mascota con estos nombres y el kiosko las usa solo (no hay que tocar código).
Formatos: `.webp`, `.png`, `.gif` (animada) o `.svg`, con fondo transparente. Alto recomendado: 440 px
(se muestra a 220 px; el doble se ve nítido en pantallas de alta densidad).

| Archivo          | Cuándo aparece                                   | Idea de pose                    |
|------------------|--------------------------------------------------|---------------------------------|
| `bienvenida.*`   | Pantalla de espera, junto a «¡Hola, crack!»      | Saludando con la mano / balón   |
| `buscando.*`     | Mientras escanea la cara                          | Lupa o mirando atento           |
| `celebra.*`      | Asistencia registrada                             | Celebrando un gol               |
| `de_nuevo.*`     | El niño ya había marcado hoy                      | Pulgar arriba / guiño           |
| `no_veo.*`       | No se detecta una cara                            | Tapándose los ojos / confundido |
| `foto_falsa.*`   | Se mostró una foto o un celular                   | Dedo «no, no»                   |
| `no_reconoce.*`  | No reconoce al niño                               | Rascándose la cabeza            |
| `error.*`        | Cámara apagada, servidor caído o sin jugadores    | Tarjeta amarilla / silbato      |

Si falta un archivo, se muestra un emoji o el balón en su lugar.
