# Mascota FA CUP (kiosko)

Pon aquí (web/public/mascota/) las imágenes de la mascota en PNG con estos nombres y el kiosko las usa solo (no hay que tocar código).
Formato: `.png` con fondo transparente. Alto recomendado: 440 px
(se muestra a 220 px; el doble se ve nítido en pantallas de alta densidad).

| Archivo          | Cuándo aparece                                   | Idea de pose                    |
|------------------|--------------------------------------------------|---------------------------------|
| `bienvenida.png`   | Pantalla de espera (abajo a la izquierda)        | Saludando con la mano / balón   |
| `buscando.png`     | Mientras escanea la cara                          | Lupa o mirando atento           |
| `celebra.png`      | Asistencia registrada                             | Celebrando un gol               |
| `de_nuevo.png`     | El niño ya había marcado hoy                      | Pulgar arriba / guiño           |
| `no_veo.png`       | No se detecta una cara                            | Tapándose los ojos / confundido |
| `foto_falsa.png`   | Se mostró una foto o un celular                   | Dedo «no, no»                   |
| `no_reconoce.png`  | No reconoce al niño                               | Rascándose la cabeza            |
| `error.png`        | Cámara apagada, servidor caído o sin jugadores    | Tarjeta amarilla / silbato      |

Si falta un archivo, no se muestra nada en ese momento: el kiosko funciona igual.
